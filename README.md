# Faceit God's Eye

Расширение для Google Chrome, предназначенное для игроков CS2 и пользователей платформы FACEIT.

Оно позволяет мгновенно находить информацию об игроках по их STEAM URL / ID / Faceit nickname.
Также расширение внедряет удобный виджет прямо на страницы Steam Community, автоматически находя привязанный аккаунт FACEIT.

---

### Установка

#### Вариант 1: Готовый билд из Releases
1. Скачайте архив с готовым билдом из вкладки **Releases** и распакуйте его (либо используйте готовую папку `dist`).
2. Откройте в браузере `chrome://extensions/`
3. Включите **Режим разработчика** (в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение** и выберите папку с билдом (`dist`).

#### Вариант 2: Сборка из исходников
1. Установите зависимости:
```bash
npm install
```
2. Укажите ключ Faceit API в `.env`:
```env
VITE_PUBLIC_API_KEY=your_faceit_api_key
```
3. Запустите сборку:
```bash
npm run build
```
4. Загрузите полученную папку `dist` в `chrome://extensions/`.
