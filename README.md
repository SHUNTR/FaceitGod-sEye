### Faceit God's Eye
Faceit God's Eye — это расширение для Google Chrome, предназначенное для игроков CS2 и пользователей платформы FACEIT.
<br/><br/>Оно позволяет мгновенно находить информацию о игроках по их STEAM URL/ID/Faceit nickname.
<br/>Расширение внедряет удобный виджет на страницы Steam Community, предоставляя автоматический поиск аккаунта faceit CS2.
